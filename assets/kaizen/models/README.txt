KAIZENVERSE 3D MODEL STARTER PACK

This pack contains six procedural low-poly/blockout GLB character models:
1. Kaisei / Wanderer
2. Kaede / Striker
3. Senka / Assassin
4. Hayami / Cutting Wind
5. Cinder Vice
6. Redline Visor

Important:
- These are prototype 3D models, not final AAA character sculpts.
- They include colored geometry, silhouette cues, weapons, accessories, and archetype-specific details.
- Use them as base meshes / blockouts for Unity, Godot, Blender, or WebGL.
- Recommended next step: retopology, rigging, UV unwrapping, texture painting, and animation cycles.

Suggested game asset pipeline:
- Import GLB into Blender.
- Clean/merge body sections as needed.
- Add armature.
- Create idle/run/jump/attack animations.
- Export optimized GLB/FBX for engine use.
